# Tokio Underground 2026

Przewodnik na wyjazd do Tokio: 106 miejsc z raportu „Tokyo Underground: alternatywny atlas Tokio”, zredagowanych, z interaktywną mapą (Leaflet + OpenStreetMap), filtrami po atlasach, wyszukiwarką i listą „Mój plan” zapisywaną w przeglądarce.

- `index.html` – gotowa strona (statyczna, bez backendu)
- `tokyo-underground-atlas.md` – tekst po redakcji
- `data/places.json` – miejsca ze współrzędnymi (orientacyjnymi, do ok. 300 m)
- `build/` – skrypty generujące stronę (`cd build && npm i && node fix.mjs && node build.mjs`)

Pinezki nie zastępują linków do Google Maps przy każdym miejscu. Status miejsc trzeba potwierdzić przed wizytą.
